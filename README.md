# 📝 文本行批量处理 (Text Lines Processor)

本地隐私优先的文本行批量整理工具 —— **纯前端 · 单文件 · 无依赖 · 数据不上传任何服务器**。

![零上传](https://img.shields.io/badge/privacy-local--only-brightgreen)

## 它解决什么
把一段「每行一条」的文本（关键词名单 / 邮箱列表 / 标签清单 / 编号 / 历史命令 / 待办行等）粘贴进浏览器，勾选需要的整理动作，一次性批量加工并导出干净结果：

- ✅ **去首尾空格**（“ 张三 ” ↔ “张三” 混着导致匹配失败的头痛）
- ✅ **删除空行**（含全空白行）
- ✅ **整行去重**（保留首次出现）
- ✅ **排序 A→Z / Z→A**（忽略大小写的自然序）
- ✅ **反转顺序**（最后一行变第一行）
- ✅ **自动编号**（1. 2. 3.…，可调分隔符与起始值）
- ✅ **每行加前缀 / 后缀**（批量套模板如 `- `、`;`、`<li>…</li>`）
- ✅ **查找替换**（在每一行内整体替换文字，也用于整行改写 / 删除指定词）
- ✅ 动作可组合：勾选多个 → 一次应用；可一键拷贝 / 下载 .txt
- ✅ 载入本地 `.txt`（UTF-8）、一键插入示例、恢复原始

## 为什么值得用
- 🔒 **全程本机浏览器运行，数据绝不上传** —— 敏感名单/邮箱敢交给它。
- 🚫 无需安装、不注册、不收费，打开网页即用。
- 单文件到底，部署极简，与工具箱其它工具风格统一。

## 快速使用
浏览器直接打开 `index.html`，或本地起静态服务：

```bash
# 任选其一
python3 -m http.server 8139   # 或 npx serve .
```

在左侧粘贴文本 → 勾选动作 → 点「⚡ 应用」→ 复制/下载结果。

## 部署（静态托管，任选）
任何静态托管均可：GitHub Pages / Netlify / Cloudflare Pages / Vercel。
参考 `docs/DEPLOY.md`（含账号红线说明）。

## 技术说明
- 纯浏览器端 JS，零第三方库、零构建步骤，动作以函数式数组变换实现，可组合叠加。
- 自检：`node` 提取内嵌脚本做语法校验通过；功能已覆盖任务要求的全部 8 类操作。
